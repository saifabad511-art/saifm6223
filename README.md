# NexusTech Platform

معمارية إنتاجية متكاملة تتضمن 8 ملفات برمجية:
- `index.html`: الهيكل الرئيسي وعناصر الـ SVG
- `css/theme.css`: متغيرات التصميم والألوان الداكنة الفاخرة
- `css/components.css`: البطاقات، الأزرار، والشبكات المتجاوبة
- `js/data.js`: طبقة البيانات المفصولة
- `js/utils.js`: دوال التفاعل والتنبيهات
- `js/app.js`: المتحكم الأساسي
